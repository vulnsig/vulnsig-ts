
# Exploring 456 OpenClaw CVEs with VulnSig


Since OpenClaw (formerly Clawdbot, Moltbot) usage exploded early in 2026, a vast array of security issues have been found within the popular AI agent. A subset of those issues are documented in Common Vulnerabilities and Exposures (CVE) records. From February through the end of May, there have been an extraordinary 456 CVEs published. While it is possible to find these CVEs via the NIST National Vulnerability Database or CVE.org, quickly scanning those results is difficult -- easily observing vulnerability severity and characteristics across this many CVEs is not possible.

The vulnsig.io site offers an alternative that both makes discovery easy and provides VulnSig glyphs for rapid visual understanding of vulnerabiltiy severity and characteristics.
